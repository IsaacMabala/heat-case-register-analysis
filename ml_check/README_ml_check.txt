Constrained machine-learning check (paper: Information gaps and derived requirements; supplementary Note S5). Target: recorded body-cramp designation among the 140 quality-valid heat-cramp and body-cramp records. Features: age, wet-bulb, dry-bulb, air velocity, level rank, occupation group, shift, season, pay-window indicator. Models: dummy, class-weighted logistic regression, shallow decision tree, restricted random forest; preprocessing within folds; repeated stratified 4-fold cross-validation (3 repeats), out-of-fold predictions and train-2023/test-2024 validation. The all-record row (n = 177, within-fold imputation) is a documentation-process sensitivity, because readings are missing for most body-cramp records. These outputs were produced by the earlier analysis version on the register as recorded and are unaffected by the adjudication (no coded statements are used as features); the duplicate row removed in revision 4 is a body-cramp record without readings, so it never entered the complete-case model, and only the all-record sensitivity row (n = 177, now 176) would change.
